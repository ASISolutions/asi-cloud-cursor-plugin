# Changelog

All notable changes to this plugin are documented here.

## 1.0.0: initial release

- Added the `asi-cloud` MCP server, pointing at ASI Cloud's hosted Streamable HTTP endpoint (`https://cloud.asi.nz/mcp`).
- Sign-in uses OAuth 2.1 with PKCE and the person's ASI Cloud login. There is no API key or client ID to configure.
- Listed in Cursor (`3.13.0`) and Grok Bot (`0.49.0`).
